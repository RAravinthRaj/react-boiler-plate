# 🚀 React Boilerplate

A modern React boilerplate built with **Vite + TypeScript**, designed for scalable and maintainable frontend development.

---

## ✨ Features

- ⚛️ React with TypeScript
- ⚡ Vite for fast builds
- 🔄 Reusable component architecture
- 🌐 API-ready structure
- 🧩 Custom hooks support
- 🎯 Clean and scalable codebase
- 📱 Responsive-ready setup
- 🔍 ESLint configured

---

## 🛠️ Getting Started

```bash
# Install dependencies
yarn install
# or
npm install

# Start development server
yarn dev
# or
npm run dev
```

---

## 🚀 Build

```bash
yarn build
# or
npm run build
```

---

## 👀 Preview Production Build

```bash
yarn preview
# or
npm run preview
```

---

## ⚙️ Environment Setup

Create a `.env` file in the root:

```
VITE_API_URL=https://your-api-url.com
```

---

## 🧪 Linting

```bash
yarn lint
# or
npm run lint
```
